## Presenting
- `→` / `Space` / click: next (also reveals quiz answers) · `←`: back
- `F`: fullscreen · `Home` / `End`: first / last slide
- Swipe on phones · Print to PDF from the browser for handouts

## Structure
```
index.html        course home page
assets/deck.css   shared slide styles + animations
assets/deck.js    shared slide engine (navigation, counters, fragments)
day-01/index.html Day 01 slides
```
To add a new day, copy `day-01/` to `day-02/`, change the slides, and link it from `index.html`.
