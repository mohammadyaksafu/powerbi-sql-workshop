01 Database vs Excel

Same rows & columns — very different jobs

📗

Excel

  • A single file, usually one person
  • Max ~1 million rows per sheet
  • Easy to break: typos, copies, “final_v3.xlsx”
  • Great for quick, small analysis
VS
🗄️

Database

  • Shared — many users at the same time
  • Millions to billions of rows
  • Rules keep data clean (types, keys)
  • Built for storing & asking questions
Excel is a notebook. A database is a library.

Homework · before Day 02

Install your tools — one command each

Right-click Start → Terminal (Admin), then run these 3 commands.

🗄️

SQL Server 2022 Express

The database server · free edition
PS> winget install -e --id Microsoft.SQLServer.2022.Express

Stores our data. During setup pick Basic; the server name will be localhost\SQLEXPRESS.

🛠️

SQL Server Management Studio

The workbench where we write SQL
PS> winget install -e --id Microsoft.SQLServerManagementStudio.22

Connect to the server, run queries and see results as tables.

📊

Power BI Desktop

Free dashboard tool
PS> winget install -e --id Microsoft.PowerBI

Builds the reports and dashboards from Day 05 onwards.

✅ Check it worked: winget list Microsoft.
🌐 No winget? Download: microsoft.com/sql-server · aka.ms/ssms · powerbi.microsoft.com/desktop
