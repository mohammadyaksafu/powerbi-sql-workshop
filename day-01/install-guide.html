Install your three tools with PowerShell

One command each for SQL Server 2022 Express, SSMS and Power BI Desktop. Plan 20–40 minutes and keep your laptop plugged in.

1 Before you start

1

Windows 10 or 11, 64-bit, with about 10 GB free on drive C: and a stable internet connection.

2

Open PowerShell as Administrator: right-click Start → Terminal (Admin) or Windows PowerShell (Admin) → click Yes.

3

Check winget is there. Run the command below. A version number such as v1.9… means you're ready.

PS> winget --version

“winget is not recognized”? See the fixes on page 2.

2 Run the three commands, one at a time

Copy each command exactly, press Enter, and wait until you see “Successfully installed” before running the next one. The two --accept-… flags answer the licence questions for you. The ` at a line end means “continues on the next line”: paste both lines together.

① SQL Server 2022 Express

the database server · free
PS> winget install -e --id Microsoft.SQLServer.2022.Express ` --accept-package-agreements --accept-source-agreements
  • If a SQL Server setup window opens, choose Basic, accept the licence and keep the default folder.
  • At the end, note the instance name: SQLEXPRESS. Your server name will be localhost\SQLEXPRESS.

② SQL Server Management Studio (SSMS)

where we write and run SQL
PS> winget install -e --id Microsoft.SQLServerManagementStudio.22 ` --accept-package-agreements --accept-source-agreements
  • This is the biggest download. Let it finish even if the progress bar seems stuck.
  • If winget says no package was found, search for the current ID: winget search "SQL Server Management Studio"

③ Power BI Desktop

builds the dashboards · free
PS> winget install -e --id Microsoft.PowerBI ` --accept-package-agreements --accept-source-agreements
  • We use it from Day 05. No account is needed to open it: close the sign-in box if it appears.

3 Check that everything worked

# All three tools should be listed PS> winget list --id Microsoft.SQLServer.2022.Express PS> winget list --id Microsoft.SQLServerManagementStudio.22 PS> winget list --id Microsoft.PowerBI # The database service should say Running PS> Get-Service 'MSSQL$SQLEXPRESS' Status Name DisplayName Running MSSQL$SQLEXPRESS SQL Server (SQLEXPRESS)

Status is Stopped? Start it with Start-Service 'MSSQL$SQLEXPRESS'. Keep the single quotes: without them PowerShell treats $SQLEXPRESS as a variable.

4 First connection in SSMS

Connect to Server window
Server typeDatabase Engine
Server namelocalhost\SQLEXPRESS
AuthenticationWindows Authentication
Encryption / certificateTick Trust server certificate

Click Connect, then New Query and run:

SELECT @@VERSION;

One row starting with Microsoft SQL Server 2022 … Express Edition means you're done. 🎉

5 If something goes wrong

ProblemFix
“winget is not recognized”Install / update App Installer from the Microsoft Store, then reopen PowerShell (Admin).
“No package found matching input criteria”Run winget source update, then search: winget search PowerBI. Copy the ID it shows.
Access denied / needs administratorClose the window and open Terminal (Admin), not the normal one.
Install stuck or failed halfwayRestart the laptop and run the same command again; winget continues safely.
SSMS: “A network-related … error” on connectCheck the server name is exactly localhost\SQLEXPRESS and the service is Running (step 3).
SSMS: certificate chain not trustedTick Trust server certificate in the connect window.
